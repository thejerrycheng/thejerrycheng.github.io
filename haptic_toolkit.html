VibraForge

A minimal, modular, and scalable toolkit for building spatial vibrotactile feedback systems. Supports up to 128 actuators, powered by per-unit microcontrollers and a clean BLE control workflow. Designed for haptics, VR, robotics, accessibility, and research.

Features

Simple, clean components. High scalability. Apple-style simplicity applied to haptics hardware.

128-Actuator Architecture

Supports 8 independent chains × 16 vibration units each. The chain-connection method keeps wiring simple and modular.

Per-Unit Microcontrollers

Each vibration unit includes its own MCU for local waveform generation. This ensures consistent timing, low latency, and smooth intensity transitions.

Fine-Grained Frequency & Intensity

16 intensity levels and multiple discrete frequencies allow expressive tactile patterns— from soft pulses to sharp alerts.

BLE + UART Hybrid Pipeline

BLE streams patterns to the control unit; UART distributes commands to each chain. Clean separation, easy debugging, fast updates.

Modular Wearable Design

Press-fit actuators attach to fabric without sewing. Reconfigure layouts in minutes — ideal for testing new haptic patterns.

Toolkit for Research & Product Exploration

A clean development process for designing tactile illusions, body-wide haptic effects, VR interactions, phoneme mapping, and more.

Examples

Phoneme Display

Mapping speech phonemes to distinct vibrotactile patterns. Used for accessibility research and sensory augmentation.

VR Fitness Jacket

A torso-mounted array provides impact cues, directional hits, and rhythmic feedback synchronized to game movement and music.

Drone Teleoperation (AeroHaptix)

A 32-actuator wearable provides spatial cues for UAV obstacle avoidance. Vibrations encode obstacle direction, distance, and urgency.

GUI Editor

Visual Pattern Authoring

Design patterns directly on a spatial grid that mirrors the physical actuator layout. Drag, activate, preview, and stream tactile effects instantly.

Waveform Controls

Choose intensity curves, pulse shapes, frequencies, or use audio-to-vibration mapping.

Real-Time BLE Streaming

The GUI streams commands live to the VibraForge control unit. Instant feedback — ideal for rapid prototyping.

Assembly Instructions

1. Connect the Chains

Wire vibration units in a simple daisy-chain using 3-pin connectors (GND, V+, UART).

2. Attach Units to Fabric

Press-fit the vibration units into the garment holes. No sewing, adhesives, or permanent fixing required.

3. Connect to the Control Unit

Plug each chain into the control unit. Power via USB-C or a 3.7V Li-ion battery pack.

4. Pair via Bluetooth

Open the VibraForge GUI → Connect → Start Streaming. The control unit handles all UART distribution internally.
