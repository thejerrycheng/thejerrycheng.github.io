⚙ View on GitHub 💻 Software Docs
Quick Start

Run the simulation.

Requirements: Python ≥ 3.9, MuJoCo ≥ 2.3. Install dependencies then launch any of the demo scripts.

# Install dependencies
cd ~/IRIS/mujoco_sim
pip install -r requirements.txt

# Run circle path tracking demo
python circle_path_tracking.py

# Cinema motion modes
python cinema_line_tracking.py --mode crane
python cinema_line_tracking.py --mode dolly
python cinema_line_tracking.py --mode pan

# Interactive teleoperation
python teleop_ik.py    # Cartesian IK teleoperation
python teleop_fk.py    # Joint-space teleoperation

The MuJoCo XML model uses the same DH parameters as the ROS hardware stack, ensuring FK/IK consistency between simulation and real deployment.

Kinematics

Analytical FK & IK

IRIS uses Denavit-Hartenberg (DH) parameters shared across the MuJoCo model, ROS TF tree, and both forward/inverse kinematic solvers. This guarantees consistency between simulation and hardware.

Forward Kinematics

# Compute end-effector pose from joint angles
python kinematics/forward_kinematics.py \
  --q 0 0 0 0 0 0

# Returns 4×4 transformation matrix T_base_ee

Implemented as closed-form matrix chain multiplication using the 6-DOF DH parameter table. No numerical approximation.

Inverse Kinematics

# Solve IK for target end-effector position
python kinematics/inverse_kinematics.py \
  --target_xyz 0.6 0.0 0.5

# Uses damped least-squares Jacobian

Damped least-squares (Levenberg-Marquardt) Jacobian IK with configurable damping factor λ. Handles singularities gracefully.

Cinema Motion Modes

Built for filmmakers.

IRIS includes three cinematography-specific motion modes. Each generates smooth, realistic camera paths commonly used in professional production.

🏗️

Crane

Vertical arc sweeping the camera upward while tracking a fixed point. Used for reveals and establishing shots.

--mode crane
🚂

Dolly

Linear push-in/pull-out maintaining camera orientation. Simulates a physical dolly track for parallax storytelling.

--mode dolly
🎥

Pan

Lateral arc sweep holding a subject in frame. Smooth rotation for product shots and subject tracking.

--mode pan

Path Planning

Motion Planners

Two classical planners are implemented in classical_planner/, enabling collision-free trajectory generation in configuration space.

🌲

RRT* (Optimal Rapidly-Exploring Random Tree)

Asymptotically optimal sampling-based planner. Finds collision-free paths in joint space. Includes rewiring step to continually improve path cost as the tree grows.

⚡

Potential Field Planner

Gradient descent on an artificial potential field with attractive goal forces and repulsive obstacle forces. Fast, reactive replanning for quasi-static environments.

📈

Trajectory Parameterization

Cubic spline and trapezoidal velocity profiles for time-optimal, smooth interpolation between waypoints. Respects joint velocity and acceleration limits.

# Run path planning in simulation
cd ~/IRIS/classical_planner

# RRT* — sampling-based, obstacle-aware
python rrt.py

# Artificial Potential Field — reactive replanning
python path_tracking.py
