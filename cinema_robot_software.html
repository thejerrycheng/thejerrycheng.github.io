Software & Firmware

A full ROS Noetic stack with 200 Hz RS-485 hardware driver, kinematic calibration, sim-to-real sync, and teleoperation interfaces — all open-source.

⚙ View on GitHub 🔩 Hardware Docs
Quick Start

Up and running in minutes.

Prerequisites: Ubuntu 20.04, ROS Noetic, Python ≥ 3.9. Then follow these steps.

1

Clone & build the workspace

# Clone the repository
git clone https://github.com/thejerrycheng/IRIS.git
cd IRIS/meng_ws

# Install ROS dependencies
rosdep install --from-paths src --ignore-src -r -y

# Build
catkin_make
source devel/setup.bash
2

Configure RS-485 serial port

# Find your RS-485 hub device
ls /dev/ttyUSB*

# Set permissions
sudo usermod -aG dialout $USER
sudo chmod 666 /dev/ttyUSB0
3

Launch the hardware driver

# Start the full hardware stack
roslaunch unitree_arm_ros iris_bringup.launch

# Verify joint states are publishing
rostopic echo /joint_states
4

Run calibration (first time only)

# Home position calibration
rosrun unitree_arm_ros calibrate_home_state.py

# Joint-space kinematic calibration
rosrun unitree_arm_ros calibrate_joint_states.py
ROS Stack

Node Architecture

All components live in the unitree_arm_ros package. The hardware driver is the core node — everything else communicates over standard ROS topics.

IRIS ROS node communication graph

iris_hw_node.py

Core hardware driver. Runs at 200 Hz via RS-485, publishes joint states, subscribes to joint commands.

200 Hz RS-485

calibrate_joint_states.py

Applies encoder offsets from calibration.yaml. Handles differential wrist mapping for joints 5 & 6.

Calibration

mujoco_visualizer.py

Streams real hardware joint states into MuJoCo in real-time for visual verification. Enables live sim–real comparison during operation.

Sim-to-Real

teach_and_repeat.py

Kinesthetic teaching interface. Record a trajectory by physically guiding the arm, then replay at any speed.

Kinesthetic

keyboard_ik_teleop.py

IK-based keyboard teleoperation. Control end-effector position in Cartesian space with WASD + arrow keys.

Teleop IK

keyboard_teleop.py

Joint-space keyboard teleop for direct joint angle control. Useful for calibration and collision testing.

Teleop FK

Sim–Real Sync

Real → MuJoCo Live Mirror

Stream real robot joint states directly into the MuJoCo model for real-time visual verification. Any motion on the physical arm is mirrored instantly in simulation. 

# Launch hardware driver first
roslaunch unitree_arm_ros iris_bringup.launch

# Then start the MuJoCo mirror
rosrun unitree_arm_ros mujoco_visualizer_calibrated.py

Requires calibrated joint states on /joint_states_calibrated. The MuJoCo viewer opens automatically and mirrors the real robot in real-time.

Calibration

Kinematic Calibration Pipeline

Calibration establishes the mapping from encoder counts to joint angles and corrects for the differential wrist coupling. Results are stored in calibration.yaml.

Step 1 — Home Position

rosrun unitree_arm_ros calibrate_home_state.py
# Move arm to known zero pose
# Press Enter to record encoder zero

Records absolute encoder values at the mechanical home position. Run once after physical assembly.

Step 2 — Joint Calibration

rosrun unitree_arm_ros calibrate_joint_states.py
# Applies offsets from calibration.yaml
# Handles differential wrist (joints 5+6)

The differential wrist (joints 5 & 6) requires special coupling correction. The calibration script handles this automatically.

Calibration Config

# meng_ws/src/unitree_arm_ros/config/calibration.yaml
joint_offsets: [0.0, -1.5708, 1.5708, 0.0, 0.0, 0.0]  # radians
differential_wrist:
  joint5_gain: 0.5
  joint6_gain: 0.5
home_encoder_counts: [2048, 2048, 2048, 2048, 2048, 2048]
Data Collection

Recording Demonstrations

Record kinesthetic demonstrations as ROS bags. The bag recorder captures synchronized joint states, RGB, and depth at each timestep. 

# Record a demonstration episode
bash ~/IRIS/meng_ws/record_data.sh -O EPISODE_NAME

# Output saved to:
# /media/jerry/SSD/rosbag_data/demo_YYYYMMDD_HHMMSS.bag

# Process bag → episode format
cd ~/IRIS/bag_reader/scripts
python process_rosbag.py \
  --bag /path/to/demo.bag \
  --out /path/to/processed_data

Processed episodes are stored in a standard format: episode_XXXX/rgb/, episode_XXXX/depth/, episode_XXXX/robot/joint_states.csv. See the Learning page for dataset details.
