About

A personal viewer for an awesome list

This is a personal, liquid-glass reimagining of the Awesome-UMI catalog — a public list of UMI-style handheld and wearable interfaces for robot tactile and manipulation data collection. I built it for my own research, so I can browse, filter, and compare these devices quickly.

Credit where it's due

Every device, every spec, and the idea of cataloguing the UMI ecosystem come from the original Awesome-UMI project by Commissure Inc and its contributors. Thank you for assembling and maintaining this list — this site is a fan-made viewer that stands entirely on your work. Device data is used under CC BY 4.0.

Built by Claude, for easy updates

This viewer was built by Claude (Anthropic) for me, Jerry Cheng, so I can keep pace with the fast-moving UMI hardware scene. It reads the same umi_devices_data.json that ships with the upstream project, so refreshing the catalog is as simple as dropping in a newer copy of that file.

Everyone is welcome

This is for my personal use, but contributions are welcome. For the data itself, please send additions and corrections upstream to Awesome-UMI so the whole community benefits. Found a bug in this viewer? Let me know.
