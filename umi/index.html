About this catalog 🐙

This is a personal, liquid-glass reimagining of the wonderful Awesome-UMI list — a public catalog of UMI-style handheld and wearable interfaces for robot tactile & manipulation data collection. I built it for my own research so I can browse, filter, and compare these devices the way my brain likes: Apple-ish, glassy, hover-to-peek, click-to-dive.

🙏 Credit where it's due

The entire dataset, scope, and the brilliant idea of cataloguing the UMI ecosystem come from the original Awesome-UMI project by Commissure Inc and its contributors. Thank you for putting this list together and maintaining it — this site is just a fan-made viewer standing entirely on your shoulders. Device data is used under CC BY 4.0.

🛠 Built by Claude, for easy updates

This viewer was built by Claude (Anthropic) for me, Jerry Cheng, so I can keep up with the fast-moving UMI hardware scene. It reads the same umi_devices_data.json that ships with the upstream project, so refreshing the catalog is as simple as dropping in a newer copy of that file — no rebuild required.

🤝 Everyone is welcome

This is for my personal use, but contributions are absolutely welcome — for the data, please send your additions and corrections upstream to Awesome-UMI so the whole community benefits. Spot a bug in this viewer? Ping me. Let's keep the list growing together.

Long live UMI 🌊🐙
